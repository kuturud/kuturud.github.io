# Changelog

This is a short, date-neutral record of the portfolio's ongoing evolution.

- Added richer project case studies with problem, approach, learning, next-step, repository, and code-excerpt fields.
- Added documented screenshot gallery support without creating placeholder screenshots.
- Added the first-person Now page and a music-learning connection.
- Expanded verified achievements and rendered the shared timeline from `achievements.js`.
- Added project search alongside category filters.
- Improved GitHub repository metadata, structured data, canonical URLs, and accessibility foundations.
- Added a print/download CV entry point and an opt-in, disabled-by-default analytics hook.
