Key Formulae

Image size (bits) width (px) × height (px) × colour depth (bits)
Image size (bytes) width × height × colour depth ÷ 8
Sound size (bits) sample rate (Hz) × bit depth × duration (s)
Sound size (bytes) sample rate × bit depth × duration ÷ 8
Stereo sound multiply final size × 2 (two channels)
Colours available 2 ^ colour depth
Data rate sample rate × bit depth (bits per second)
